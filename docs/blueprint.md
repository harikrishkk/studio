# **App Name**: MapleLeafDev

## Core Features:

- About Me Section: Display a concise bio, professional skills, and links to social profiles (YouTube, Blog).
- Work Experience Timeline: Showcase previous work experiences with company logos and short descriptions.
- Contact Form: A simple form for visitors to send messages directly.

## Style Guidelines:

- Primary color: Forest green (#228B22) to represent Canadian landscapes.
- Secondary color: Maple leaf red (#FF4500) for accents and highlights.
- Accent: Golden yellow (#FFD700) for interactive elements.
- Use a monospace font for a clean and modern look. Consider system fonts or a web-safe monospace font.
- Single-page layout with smooth scrolling to each section.
- Use icons to represent different sections and links.
